# Hospital Management System

A full-stack Hospital Management System built with Django REST Framework
and React.

## Technologies

### Backend
- Python
- Django
- Django REST Framework
- JWT Authentication

### Frontend
- React
- Vite
- React Router
- CSS

## Features

- User Registration and Login
- Role-based Authentication
- Admin Dashboard
- Doctor Management
- Patient Management
- Department Management
- Appointment Management
- Prescription Management
- Medicine Management
- Billing Management
- JWT Authentication
